## ✨ Why TypeMaster?

TypeMaster turns typing practice into a competitive race. Choose your difficulty, launch into a live typing course, compete against computer-controlled racers, and use your results to sharpen your technique.

## 🎯 Features

| Feature | Description |
| --- | --- |
| **Three difficulty modes** | Practice with easy, medium, or hard text |
| **Live race track** | Watch your progress and computer-controlled competitors in real time |
| **Detailed metrics** | Track WPM, accuracy, errors, mistakes, streaks, and completion |
| **Race results** | Review your placement on a full leaderboard |
| **Performance charts** | Analyze speed, errors, and accuracy across the course |
| **Theme switching** | Use a comfortable light or dark interface |
| **Responsive design** | Practice comfortably across desktop and smaller screens |

## 🏁 How it works

```text
Choose a difficulty  →  Type the course  →  Race the bots  →  Study your results
```

1. Select a difficulty from the landing page.
2. Start typing to launch the race.
3. Keep your accuracy high while chasing the finish line.
4. Review your speed, mistakes, charts, and final placement.
5. Race again and improve your personal performance.

## 🚀 Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm

### Installation

```bash
git clone https://github.com/itsrajcode/TypeMaster.git
cd TypeMaster
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## 📜 Available scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Build the app for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Check the codebase with ESLint |

## 🧭 App routes

| Route | Screen |
| --- | --- |
| `/` | Landing page and difficulty selection |
| `/practice` | Live typing race |
| `/results` | Results, charts, and leaderboard |
